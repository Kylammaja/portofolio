CREATIVE PORTFOLIO — FILE TERPISAH
=================================

FILE UTAMA:
- index.html    = Struktur halaman Home
- style.css     = Seluruh tampilan dan animasi CSS
- script.js     = Navbar, scroll reveal, parallax, carousel 5 kartu
- assets/       = Gambar placeholder SVG (tidak ada error 404)

CARA MENJALANKAN:
1. Ekstrak folder ZIP.
2. Buka folder di VS Code.
3. Jalankan index.html dengan Live Server.
4. Pastikan ketiga file berada di folder yang sama.

MENGGANTI FOTO:
- Hero: cari assets/portrait-placeholder.svg di index.html,
  ganti dengan images/foto-saya.png setelah memasukkan foto PNG.
- Activities: cari assets/activity-01.svg dst., ganti dengan
  images/activities/activity-01.jpg dst. dan pastikan gambarnya ada.
- Projects: cari assets/project-web.svg dst., ganti dengan screenshot aslimu.

CATATAN:
- File HTML ini merupakan REKONSTRUKSI halaman Home dari kode yang
  kita diskusikan. Bukan edit byte-for-byte dari file lokalmu, karena
  file index.html aslimu belum dikirimkan.
- Halaman skills.html, activities.html, projects.html, contact.html
  BELUM disertakan; link menuju halaman detail tersebut dapat 404
  sampai file detail yang bersangkutan kamu buat/letakkan sejajar.
- Assets SVG hanya placeholder, bukan dokumentasi/foto aslimu.
- Reduced Motion dihormati bila aktif pada sistem.
- Carousel berisi 5 kartu. JavaScript memakai totalActivities yang
  dideklarasikan dengan benar; jika JavaScript gagal, kartu tetap bisa
  digeser horizontal.
